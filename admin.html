Gmail Notification Setup

Send automatic confirmation and rejection emails from the parish Gmail for free using Google Apps Script.

  1. Open script.google.com while signed into the parish Gmail account and create a new project with the code from gmail-apps-script/Code.gs.
  2. Click Deploy → New deployment → Web app.
  3. Set Execute as: Me and Who has access: Anyone, then authorize and copy the /exec URL.
  4. Paste the Web App URL below, test it, and save.
